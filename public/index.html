Sobre mí

Soy estudiante de programacion y desarrollador junior. Me interesa el desarrollo web full stack, las interfaces limpias y las APIs bien estructuradas.

Vconvert es un proyecto practico para aplicar Node.js, Express, JavaScript y diseno responsivo en una herramienta real de descarga de medios.

Documentación

  • Frontend: HTML, CSS y JavaScript vanilla, con diseno oscuro y adaptado a moviles.
  • Backend: Node.js, Express, CORS y @distube/ytdl-core para resolver la informacion de YouTube.
  • API: GET /api/info valida la URL y devuelve metadatos y formatos disponibles.
  • Descarga: GET /api/download elige el formato, transmite el archivo y cancela el stream si el cliente se desconecta.
